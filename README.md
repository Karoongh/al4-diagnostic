# عیب‌یابی گیربکس AL4 / DP0

پلاگین وردپرس تخصصی برای تشخیص هوشمند مشکلات شیرهای برقی (سلونوئید) و فشار روغن گیربکس‌های **AL4** و **DP0** (رنو، پژو، سیتروئن).

**نسخه:** 2.0.0  
**نویسنده:** [Karoongh](https://github.com/Karoongh)  
**مجوز:** GPL-2.0-or-later

## ویژگی‌ها

- رابط فارسی، راست‌چین و موبایل‌فرندلی با تب‌های مرحله‌به‌مرحله
- انتخاب کدهای خطای رایج رنو (DF226، DF049، DF018 و ...)
- علائم ازپیش‌تعریف‌شده (لگد سرد، Limp Mode، براده فلزی و ...)
- ورود مقاومت شیرها و نتایج تست فشار / Stall با گزینه‌های ازپیش‌تعریف‌شده
- تشخیص هوشمند محل ایراد + مراحل پیشنهادی از ساده به پیچیده
- چک‌لیست بعد از تعمیر (پاک کردن خطا، RZ005، CF074 و ...)
- جداول مرجع مقاومت استاندارد و اشتباهات رایج
- سبک و کم‌حجم — فقط در صفحه‌ای که شورت‌کد دارد لود می‌شود

## نصب

1. پوشه `al4-diagnostic-plugin` را در مسیر `/wp-content/plugins/` کپی کنید  
   **یا** فایل ZIP را از بخش Releases دانلود و از پیشخوان وردپرس نصب کنید.
2. از **افزونه‌ها** پلاگین را فعال کنید.
3. یک برگه یا نوشته بسازید و شورت‌کد زیر را قرار دهید:

```
[al4_diagnostic]
```

## نحوه استفاده

1. **شروع سریع** — مدل خودرو و بررسی‌های اولیه (باتری، روغن، کانکتور)
2. **کد خطا** — انتخاب DFهای خوانده‌شده از دیاگ
3. **علائم** — علائم مشاهده‌شده روی خودرو
4. **مقادیر** — مقاومت شیرها، تست فشار خط، تست Stall
5. **نتیجه** — تشخیص + مراحل کار + کارهای بعد از تعمیر

## مقادیر استاندارد استفاده‌شده

| قطعه | مقاومت |
|------|--------|
| EVM / EVLU | ۱ ± ۰.۱۲ اهم |
| EVS (تعویض دنده) | ۴۰ ± ۲ اهم |
| سولنوئید دبی مبدل | ۴۰ ± ۴ اهم |
| سنسور دور توربین | ۳۰۰ ± ۴۰ اهم |
| سنسور سرعت خروجی | ۱۲۰۰ ± ۲۰۰ اهم |

## سلب مسئولیت

این ابزار یک **راهنمای تشخیصی** است و جایگزین دستگاه دیاگ، دفترچه تعمیرات رسمی رنو/PSA و تجربه مکانیک متخصص نیست. قبل از تعویض قطعه گران، تست‌های توصیه‌شده را انجام دهید.
